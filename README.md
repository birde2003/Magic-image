# Magic-image

AI Image Generation interface using Tongyi MAI-Z Image Turbo

## Installation

Clone the repository and install dependencies:

```bash
git clone https://github.com/birde2003/Magic-image.git
cd Magic-image
pip install -r requirements.txt
```

## Usage

Run the Gradio web interface:

```bash
python app.py
```

The app will start on `http://0.0.0.0:7860`

## About

This is a demonstration interface for AI image generation using Tongyi MAI-Z Image Turbo model.

**Note:** This is a demo interface. To use the actual Tongyi MAI-Z model, you would need to integrate with Alibaba Cloud's API service and provide proper authentication.

## Features

- Simple and intuitive web interface powered by Gradio
- Text-to-image generation
- Customizable image parameters
- Real-time image preview
